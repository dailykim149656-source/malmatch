# Korean Naturalness Check

Use this skill when Korean dialogue needs a focused pass for grammar, native expression, or spoken rhythm.

Check:

- 조사, 어미, 연결어, 높임 표현의 문법성
- 되/돼, 어떡해/어떻게, 아니에요, 할게, 며칠, 의존 명사 띄어쓰기 같은 흔한 표기/문법 후보
- 영어식 직역, 번역투, 한국어에서 덜 자연스러운 결합
- 실제 구어의 짧은 반응, 생략, 호흡, 말 끊김
- 캐릭터와 관계를 해치지 않는 최소 수정안

Do not rewrite the whole scene. Preserve the intended meaning, relationship, and character function.
