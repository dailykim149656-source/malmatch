# 데이터셋 사용과 공개 배포 원칙

말매치 Malmatch는 AI Hub 등에서 받은 원본 데이터를 저장소에 포함하거나 재배포하지 않습니다.
공개 저장소에는 로컬에서 데이터를 분석하는 코드, MCP 서버, 스키마, 문서, 합성 예시만 포함합니다.

## 기본 원칙

- 원본 데이터셋은 사용자가 각 제공처의 이용정책에 따라 직접 신청하고 내려받습니다.
- 공개 저장소에는 원본 zip/json/xlsx/txt, 발화 원문, 요약문, 샘플 문장을 넣지 않습니다.
- `.malmatch/data_inventory.json`, `.malmatch/pattern_profile.json`, `.malmatch/private_pattern_bank.json` 같은 내부 분석 산출물은 로컬 전용이며 공개 배포하지 않습니다.
- private pattern bank는 원문을 저장하지 않더라도 데이터셋에서 만든 재가공 산출물로 해석될 수 있으므로 릴리스 파일, 패키지, 예시 데이터에 포함하지 않습니다.
- 공개 예시는 직접 작성한 합성 문장만 사용합니다.
- 데이터셋 이름과 출처는 밝히되, 데이터 자체나 데이터 일부를 복원할 수 있는 세밀한 표본은 공개하지 않습니다.

## 허용하는 공개 범위

- 데이터셋을 로컬에서 스캔하는 Python 도구
- 원문을 저장하지 않는 통계 추출 로직
- MCP 도구와 스키마
- 루브릭, 프롬프트 템플릿, 사용 설명서
- 직접 작성한 합성 good/bad 예시
- AI Hub 등 공식 출처 링크와 활용 사실 설명

## 공개하지 않는 범위

- AI Hub 원본 파일과 압축 해제 결과
- 데이터셋 발화, 요약, 문서, 주석 샘플
- 로컬에서 생성한 `.malmatch/*.json`
- private pattern bank를 포함한 재가공 데이터 파일
- 원자료 일부를 추정할 수 있을 정도로 작은 표본 단위의 상세 통계

## 상업용 여부와 별개로 지키는 규칙

비상업적 사용이라도 데이터 재배포 제한은 별도로 적용될 수 있습니다.
따라서 말매치는 상업용 여부와 관계없이 원본 데이터와 재가공 데이터 파일을 공개하지 않는 쪽을 기본값으로 둡니다.

AI Hub FAQ는 AI Hub 데이터로 학습해 만든 모델과 서비스의 배포 및 활용 가능성을 안내하지만, 데이터를 재가공해 배포하는 행위는 원칙적으로 불가하다고 설명합니다.
AI Hub 이용정책도 제공받은 데이터를 승인 없이 제3자에게 열람, 제공, 양도, 대여, 판매하지 말 것을 요구합니다.

## 사용자에게 요구되는 일

1. 필요한 데이터셋을 제공처에서 직접 신청하고 내려받습니다.
2. 로컬 저장소에서 `tools/dataset_inventory.py`와 `tools/build_private_pattern_bank.py`를 실행합니다.
3. 생성된 `.malmatch/private_pattern_bank.json`은 자신의 로컬 환경에서만 사용합니다.
4. 공개 repo, 패키지, 이슈, PR, 예시 파일에 원문 데이터나 private bank를 첨부하지 않습니다.
