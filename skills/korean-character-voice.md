# Korean Character Voice

한국어 캐릭터 대사를 검수할 때 쓰는 상위 스킬입니다.
아래 순서로 하위 스킬을 호출합니다.

1. `character-voice-check.md`로 캐릭터 보이스 기준을 확인한다.
2. `relationship-tone-check.md`로 관계선과 감정 반응을 본다.
3. `korean-speech-level-check.md`로 어체 일관성을 점검한다.
4. `korean-humor-audit.md`로 농담과 오글거림 위험을 본다.
5. `korean-dialogue-audit.md`로 최종 결과를 정리한다.

항상 원문 데이터셋 문장을 예시로 끌어오지 않고, 사용자가 제공한 프로젝트 문장과 직접 작성한 수정안만 다룹니다.
